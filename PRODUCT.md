# NearMyst

## Product

NEAR testnet mystery-pack launchpad. Buy packs, wait one block, open for FT rewards; creators deposit inventory and activate machines. Demo with test tokens — not real money.

## Audience

Hackathon judges and NEAR builders evaluating a Games / real-economy demo. First-time testnet users who need wallet + token onboarding.

## Surfaces

| Surface | Mode | Job |
|---------|------|-----|
| `/` | Persuade | Explain the product; drive Explore |
| `/explore`, `/machine/[id]`, `/inventory`, `/create`, `/result` | Operate | Complete buy / open / create / claim tasks |
| Pack open / reveal | Experience | Trunk shake → lid open → win amount |

## Brand pins (do not replace)

- Base `#0C0A08`, raised `#16120E`, accent brass `#E0B84A`
- Type: Fraunces (display) + Source Sans 3 (body) + DM Mono (ids)
- Motif: Mystery Trunk (shake → open) + logo (brass NEAR N + green mystery box)
- Logo asset: `web/public/brand/logo-v2.png`
- Win headline: `{amount} ${tokenSymbol}` (e.g. `500 $myst`)
- Demo FT display ticker: `$myst` (account stays `ft.nearmyst.testnet`)
- Honesty: testnet RNG disclaimer always visible; no fake stats

## Non-goals

- Contract / wallet / odds / tx payload changes
- Light theme
- Invented partners, wins, or social proof
- Purple / violet brand accent (retired)
